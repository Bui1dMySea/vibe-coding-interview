# Vibe Coding 面试题 · 搜题三阶段过滤器

一道 30 分钟实操面试题（改编自真实搜题召回链路），用于考察 AI 辅助编程时代候选人的真实工程能力：读 spec、对脏数据建立防御、验证自己的输出、应对中途需求变更。

任务本身对 AI 完全开放——允许候选人在面试中随意使用任何 AI 工具。设计上题目不靠「藏答案」区分人：spec 内 bug 与数据脏值是入场券层，中途变更卡与现场辩护才是真区分层。

## 文件

| 文件 | 说明 |
|---|---|
| `TASK.md` | 题目说明（先读这个） |
| `recall_filter.py` | 带坑的待修骨架（三个阶段函数） |
| `run_pipeline.py` | 入口脚本，对 mock 数据跑全链路 |
| `mock_input.json` | 2 个 query 的模拟召回结果（**含真实业务里出现过的脏数据形态**） |

## 使用

```bash
python3 run_pipeline.py    # 初始状态会崩溃——这就是题目的一部分
```

修复目标与验收口径见 `TASK.md`；要求保持 `recall_filter.py` 文件名与三个函数名不变。

## 说明

- 面试官侧材料（坑位全解、参考解、验收测试、判卷流水线）不在此仓库
- 题目允许候选人全程使用 AI 工具——区分度不靠藏答案，靠过程与现场辩护
